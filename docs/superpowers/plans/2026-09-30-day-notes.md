# Day Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private, editable note per timesheet day, added from the Today screen, the Timesheets table and the desktop widget, never shown in the PDF or the Google Sheet.

**Architecture:** Notes live in their own map in the Rust store (`Store::notes`, keyed by the same New York date as `Store::days`), saved through a new `save_note` command that reuses `update_data` (save + backup + broadcast). The `View` sent to both windows carries `notes`; the UIs read them with a shared `noteFor()` helper.

**Tech Stack:** Tauri 2 (Rust), plain HTML/CSS/JS (no bundler), `cargo test` for unit tests.

Spec: `docs/superpowers/specs/2026-09-30-day-notes-design.md`

## Global Constraints

- One note per day, key `yyyy-mm-dd` (New York date, same as `Store::days`).
- Notes are trimmed; empty text deletes; max 500 characters → error "Keep notes under 500 characters.".
- Never in the PDF, never sent to the Google Sheet, never marks a date dirty. Included in `backup_json()`.
- Old `store.json` files without `notes` must still load.
- Copy: Today placeholder "Add a note for today (only you see this)".
- Don't commit until Lei approves; work stays on branch `widget-light-contrast`.

    /// Set a day's note; blank text removes it.
    pub fn set_note(&mut self, date: &str, text: &str) -> Result<(), String> {
        let text = text.trim();
        if text.chars().count() > NOTE_MAX_CHARS {
            return Err(format!("Keep notes under {NOTE_MAX_CHARS} characters."));
        }
        if text.is_empty() {
            self.notes.remove(date);
        } else {
            self.notes.insert(date.to_string(), text.to_string());
        }
        Ok(())
    }
```

/** A day's private note ('' when none). Notes never go into the PDF or the sheet. */
function noteFor(view, date) {
  return (view && view.notes && view.notes[date]) || '';

/** Save (or, with blank text, delete) a day's note; returns the new view. */
function saveNote(invoke, date, text) {
  return invoke('save_note', { date, text });

// ---- Day notes ----

function fitNote(el) {
  el.style.height = 'auto';
  el.style.height = el.scrollHeight + 'px';
}

let noteSavedTimer = null;
async function saveTodayNote() {
  const box = $('todayNote');
  const key = today().key;
  const text = box.value.trim();
  if (text === noteFor(view, key)) return;
  const before = view.notes;
  // Show the new text right away so the 1 s re-render doesn't flash the old note.
  view.notes = { ...view.notes };
  if (text) view.notes[key] = text; else delete view.notes[key];
  try {
    view = await saveNote(invoke, key, text);
    const tag = $('todayNoteSaved');
    tag.hidden = false;
    clearTimeout(noteSavedTimer);
    noteSavedTimer = setTimeout(() => { tag.hidden = true; }, 2000);
    if (!$('view-timesheets').hidden) renderTimesheets();
  } catch (e) {
    view.notes = before;
    toast(String(e), true);
    box.focus(); // keep what they typed
  }
}
```
